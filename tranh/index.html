Dữ liệu thống kê

Thống kê lưu trên máy này và trong file thongke-in.json ở thư mục lưu file cần in. Các máy cùng chọn một thư mục dùng chung (thư mục mạng) sẽ thấy chung số liệu.

Bảng phân loại sản phẩm

Mỗi phân loại là một thư mục cùng tên, nằm trong thư mục lưu file cần in. Sản phẩm không có phân loại được lưu vào thư mục chung.

Tên phân loại (tên thư mục)Từ khóa tự nhận, cách nhau dấu phẩy

Sản phẩm

Sản phẩm lấy theo cột Tên phân loại hàng, bỏ phần cỡ sau dấu phẩy. Để “Theo từ khóa” thì app tự nhận theo từ khóa ở bảng trên. Thư mục lấy file để trống thì app tự tìm trong cả kho; có điền thì chỉ tìm trong thư mục đó (phải nằm trong thư mục lấy file chung).

File Excel cần cột Tên phân loại hàng, thêm cột Phân loại và/hoặc Thư mục lấy file. Phân loại chưa có sẽ được tạo mới.

Máy này

ID do app tạo và gắn với trình duyệt trên máy này. Xóa dữ liệu trình duyệt hoặc đổi trình duyệt sẽ ra ID mới; khi đó bạn chỉ cần gán tên người cho ID mới.

Chỉnh kích thước

Đổi cỡ không làm thay đổi điểm ảnh: app chỉ ghi lại kích thước in trong file, nên in to hơn thì số điểm ảnh trên mỗi inch giảm và app sẽ cảnh báo khi xuống dưới mức này. Khác tỉ lệ thì app cắt phần giữa; nếu phải cắt quá mức trên, đơn được chuyển sang “Cần xem lại” thay vì tự cắt.
